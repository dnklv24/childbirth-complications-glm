# Predictive Analysis of Childbirth Complications

## Overview
This project involves a data-driven analysis of the factors influencing childbirth complications, utilizing the Spanish "Nacimientos 2022" dataset (over 329,000 observations). The goal is to evaluate how maternal age and the number of previous births impact the likelihood of complications during delivery.

## Tech Stack
* **Language:** R
* **Libraries:** `ggplot2`, `pR2`
* **Methods:** Binomial Logistic Regression (GLM), ROC/AUC evaluation, McFadden’s Pseudo-R²

## Key Features
* **Data Segmentation & Visualization:** Demographic segmentation and risk trend visualization using `ggplot2`.
* **Predictive Modeling:** Built a binomial logistic regression model to estimate the probability of complications.
* **Statistical Validation:** Evaluated model capacity using ROC curves and AUC metrics to extract meaningful healthcare insights.

* Note: The raw dataset is not included in this repository due to size limits, but can be provided upon request.
